# Máquina skills

Portable skills for governed agent-assisted software delivery.

Install all skills for supported agents:

```sh
npx skills add maquina-la/skills --all
```

Install one skill for Codex and Claude Code:

```sh
npx skills add maquina-la/skills --skill maquina-intent -a codex -a claude-code
```

Available skills:

- `maquina-intent` — create a scoped, linked work intent before implementation.
- `maquina-pr-advisory` — prepare and interpret the observe-only PR operational advisory.

The skills require no model provider, hosted Máquina service, or source-code egress. Review each skill before installation and keep the repository Factory Contract authoritative.
